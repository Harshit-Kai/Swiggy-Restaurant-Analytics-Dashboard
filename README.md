# Swiggy Restaurant Analytics Dashboard

## Dashboard Overview

The dashboard provides:

- Restaurant performance analysis
- Cuisine distribution analysis
- Area-wise restaurant concentration
- Price trend analysis
- Delivery time insights
- Interactive filtering for detailed exploration

## Business Objective

The purpose of this project is to analyse restaurant data from Swiggy and identify:

- Popular food categories
- Areas with the highest restaurant density
- Expensive restaurant locations
- Delivery performance trends
- Key business metrics for decision-making

## Key Performance Indicators (KPIs)

- Average Rating
- Average Price
- Total Restaurants
- Average Delivery Time

## Dashboard Features

### Restaurant Analysis

- Top 5 Most Served Food Types
- Top 10 Areas with Most Restaurants

### Price Analysis

- Most Expensive Areas
- Area-wise Price Comparison

### Geographic Analysis

- Top Cities with Most Restaurants
- Interactive Map Visualization

### Filter Panel

- City Filter
- Area Filter
- Restaurant Filter
- Address Filter

## Key Insights

- Certain food categories dominate restaurant offerings.
- Restaurant concentration is highly clustered in specific areas.
- Premium locations show significantly higher average prices.
- Delivery times vary considerably across cities.
- Large metropolitan cities contain the majority of restaurant listings.

## Business Recommendations

- Expand operations in high-demand areas.
- Promote top-performing cuisines.
- Optimize delivery routes in slower regions.
- Monitor pricing strategies in premium markets.
- Increase visibility for highly rated restaurants.
